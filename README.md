# Void Drifter — путеводитель по проекту

Космический шутер-оборона на Godot 4.7: защищаем 5 планет от волн врагов,
собираем ресурсы и улучшаем корабль на станциях.

Запуск — **F5** (главная сцена `scenes/main.tscn`).

---

## Как править уровень

Откройте **`scenes/levels/sector_01.tscn`**. Жёлтый круг — граница сектора
(радиус задаётся в инспекторе у корня `Sector01` → *World Radius*). Враги
прилетают из-за этой границы.

Внутри уровня папки:

| Папка | Что в ней |
|---|---|
| `Planets` | Планеты |
| `Defenses/<Планета>Defense` | Пост и турели каждой планеты |
| `AsteroidFields` | Поля метеоритов |
| `PlayerSpawn` | Точка появления и возрождения игрока |

Папки — это просто порядок; их можно переименовывать и создавать свои (`Node2D`).

### Передвинуть что-нибудь
Выделите узел и тащите мышкой — всё.

### Добавить планету
1. Перетащите `scenes/world/planet.tscn` из файловой панели в папку `Planets`.
2. В инспекторе:
   - **Kind** — вид (terra, lava, ice, toxic, mars); картинка меняется сразу;
   - **Max Hp** — прочность;
   - **Is Home** — домашняя планета: если её уничтожат — поражение. Такая должна быть одна.

### Добавить оборону к планете
Перетащите рядом с планетой `defense_post.tscn` и/или `turret_blaster.tscn` /
`turret_missile.tscn`. **Они сами привяжутся к ближайшей планете** при старте игры.
Если нужно привязать к конкретной — укажите её в поле **Planet** в инспекторе.

- Пост: **Max Flies** (сколько Мух держит), **Fly Respawn** (раз в сколько секунд
  новая), **Max Heavies** (союзные ракетоносцы), **Aura Radius** (радиус магазина —
  голубой круг в редакторе).
- Турель: **Attack Range** (оранжевый круг в редакторе следует за значением), **Turn Speed**, **Max Hull**.

### Добавить поле метеоритов
Перетащите `asteroid_field.tscn` в `AsteroidFields`. В инспекторе:
**Count** (сколько камней), **Radius**, **Kind** (random / rock / iron / ice /
crystal; кристаллические дают кристаллы), доли крупных/средних, скорость дрейфа.
Камни раскладываются случайно при каждом запуске.

## Как менять характеристики

Всё — в инспекторе, код трогать не нужно.

**Корабли** (`scenes/ships/*.tscn`, корневой узел):
- *Hull*: Max Hull, урон от столкновений, **Loot** (что выпадает с врага), размер взрыва;
- *Engine*: Thrust (ускорение), Max Speed, Drag (как быстро гаснет инерция), Turn Speed;
- у ИИ: **Aggro Range** (дальность реакции), **Max Shield** (щит, как у Корсара).

**Оружие** — дочерний узел **`Weapon`** у корабля или турели:
- Damage, Speed, **Interval** (между выстрелами), **Magazine** + **Reload Time**
  (очередь и перезарядка; 0 = без магазина), Count/Spread (веер), Blast Radius;
- группа *Missiles*: поворотливость, ускорение, время жизни ракет, **Show Rack**
  (ракеты висят на корпусе и отрастают при перезарядке);
- точки вылета — дочерние **`Muzzle1, Muzzle2…`** (Marker2D): двигайте их мышкой,
  стреляют по очереди в порядке списка.

**Игрок** (`scenes/ships/player.tscn`): группа *Player* — базовая прочность,
тяга, скорость, мощность заднего хода и стрейфа, время возрождения. Оружие игрока
улучшается в магазине, его уровни — в `scripts/arsenal.gd`; цены — в
`scripts/ui/shop_ui.gd`.

**Волны** — узел `WaveDirector` в `scenes/main.tscn`: задержка первой атаки,
с какой волны атакуют две планеты, когда можно нападать на дом, сколько волн до
победы, сила волн (*Budget Base* + *Budget Per Wave* × номер волны), паузы между волнами.
Состав волны (сколько истребителей/Корсаров/тяжёлых) — `_composition()` в
`scripts/wave_director.gd`.

**Камера** — узел `Camera` в `main.tscn`: плавность, упреждение, пределы зума.

**Фон** — `scenes/background/space_background.tscn`: у каждого слоя `Scroll Scale`
(глубина) и `Modulate` спрайта (яркость); декоративные галактики/планеты можно двигать.

## Управление

| Клавиша | Действие |
|---|---|
| W / S | тяга вперёд по носу / назад |
| A / D | стрейф влево / вправо |
| Мышь | поворот носа и прицел |
| ЛКМ / ПКМ / Пробел | бластер / залп самонаводящихся ракет / плазменная бомба |
| Колесо, + / − | зум |
| E | магазин (внутри ауры поста), игра на паузе |
| Tab | карта сектора (колесо — масштаб, перетаскивание — прокрутка) |
| Esc | пауза: схема управления, музыка, рестарт |

## Для разработчика

- **Команды и слои столкновений** — `scripts/game.gd` (синглтон `Game`): игрок,
  метеориты, планеты, союзники, враги, ракеты союзников/врагов.
- Союзный огонь не наносит урона планетам; кратеры оставляют только враги.
- Корабль собирается из сцены: `Sprite` (перекрашивается по команде),
  `CollisionShape2D` (круг — радиус используется для прицеливания), узлы `Weapon`,
  маркеры `Exhaust*` (там появляется выхлоп).
- **Новый вариант врага** (например, «элитный истребитель»): скопируйте сцену из
  `scenes/ships/`, поменяйте спрайт и цифры; поле **Kind** выбирает поведение
  (fly / fighter / corsair / heavy / carrier). Добавьте сцену в словарь
  `AIShip.SCENES` (`scripts/ai_ship.gd`) под новым именем и впишите это имя в
  `_composition()` директора волн — он начнёт появляться в атаках.
- **Автотесты** (запускают игру, играют сами, сохраняют скриншоты в
  `%APPDATA%/Godot/app_userdata/Void Drifter/`):

  ```
  Godot_v4.7.2-stable_win64_console.exe --path . -- --autotest
  ```
  Режимы: `--tunnel` (стрельба по планете с дырой), `--controls`, `--planetdeath`,
  `--carvestress`, `--field` (видимость метеоритов), `--waves` (состав волн).
- **Перегенерация ассетов** (Python + numpy + pillow):
  `python tools/gen_assets.py` (планеты, метеориты, фон), `tools/gen_units.py`
  (корабли, турели, посты), `tools/gen_audio.py` (звуки и музыка).
